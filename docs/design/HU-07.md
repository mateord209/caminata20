# Diseño HU-07 — Mensajes motivacionales en los recordatorios

**Responsable:** Thomas Montoya Magón · **Puntos:** 2 · **Sprint:** 2

## Estado actual

`data/local/MotivationalPhrases.kt` tiene 17 frases y `domain/usecase/FraseMotivacionalUseCase.kt`
rota una cada 4 horas. La frase se muestra como “Tip del día” en Inicio, pero **no aparece en las
notificaciones**. El caso de uso importa `data.local`, violando la regla de dependencias.

## Decisión de interpretación del CA-02

El CA dice “sin repetir la misma frase consecutivamente en un período de 24 horas”. Se implementa
como: **la siguiente frase no puede ser igual a la última mostrada si esa última se mostró hace
menos de 24 h**. No se exige unicidad absoluta de las 20+ frases en 24 h porque con recordatorios
cada 30–60 min sería imposible y no es lo que pide el texto.

## Diseño

### Dominio

| Clase | Responsabilidad |
|---|---|
| `Phrase` | `id`, `text`, `category` (motivacional/ergonómica). |
| `PhraseRepository` | Interfaz: `current(): Flow<Phrase>` y `suspend fun next(): Phrase`. |
| `PhraseSelectionPolicy` | Función pura: dada la lista, la última frase y `now`, devuelve candidatas. |
| `GetPhraseUseCase` | Carga la última, aplica la policy, elige con `Random` inyectado y persiste. |

### Datos

| Clase | Responsabilidad |
|---|---|
| `PhraseCatalog` | Catálogo local de 20+ frases (mínimo 15 según CA-01). |
| `PhraseStateStore` | Persistencia de `lastPhraseId` y `lastShownAt` en DataStore. |
| `LocalPhraseRepository` | Implementa `PhraseRepository` usando catálogo + store + `Clock` + `Random`. |

### Notificaciones / UI

| Clase | Responsabilidad |
|---|---|
| `NotificationContentBuilder` | Función pura que arma título, texto y `bigText` con ejercicio + frase. |
| `PauseNotifier` | Solo construye y muestra; recibe `GetPhraseUseCase` por constructor. |
| `HomeViewModel` | Expone `current()` del repositorio; el “Tip del día” se actualiza con Flow. |

## Dependencias

```
PauseNotifier ──► GetPhraseUseCase ──► PhraseRepository + PhraseSelectionPolicy + Clock + Random
HomeViewModel ──► PhraseRepository
LocalPhraseRepository ──► PhraseCatalog + PhraseStateStore
```
